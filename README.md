# 🩺 پیش‌بینی دیابت با یادگیری ماشین

پروژه‌ای آموزشی برای بررسی داده‌های بالینی و پیش‌بینی دیابت با استفاده از دو الگوریتم **K-Nearest Neighbors (KNN)** و **Decision Tree** روی دیتاست Pima Indians Diabetes.

## 📁 فایل‌های پروژه

```
├── diabetes.csv        # دیتاست
├── Knn.ipynb           # تحلیل و مدل KNN
├── DT.ipynb    # تحلیل و مدل درخت تصمیم
└── requirements.txt    # وابستگی‌های پایتون
```

## 🗂 دیتاست

داده شامل **۷۶۸ نمونه**، هشت ویژگی و ستون هدف `Outcome` است (`1` = دیابت، `0` = بدون دیابت).

| ویژگی | توضیح |
|---|---|
| `Pregnancies` | تعداد بارداری |
| `Glucose` | غلظت گلوکز پلاسما |
| `BloodPressure` | فشار خون دیاستولیک (mm Hg) |
| `SkinThickness` | ضخامت چین پوستی سه‌سر بازو (mm) |
| `Insulin` | انسولین سرم دوساعته (mu U/ml) |
| `BMI` | شاخص توده‌ی بدنی |
| `DiabetesPedigreeFunction` | شاخص سابقه‌ی خانوادگی دیابت |
| `Age` | سن |

## ⚙️ روند تحلیل

- بررسی نوع داده‌ها، مقادیر یکتا و داده‌های گمشده.
- جایگزینی سه مقدار خالی در `BloodPressure`، `SkinThickness` و `BMI` با میانگین ستون.
- مصورسازی توزیع ویژگی‌ها و بررسی داده‌های پرت با نمودارهای میله‌ای و Boxplot.
- حذف ردیف‌ها با آستانه‌های مشخص برای ویژگی‌ها؛ در نوت‌بوک‌ها تعداد نمونه‌ها پس از این مرحله ۶۴۷ گزارش شده است.
- تقسیم داده به مجموعه‌های آموزش و آزمون با نسبت ۸۰/۲۰ و مقیاس‌بندی ویژگی‌ها با `MinMaxScaler`.
- آموزش و مقایسه‌ی KNN و درخت تصمیم با معیار دقت (Accuracy).

## 📈 نتایج ثبت‌شده

اعداد زیر از خروجی‌های ذخیره‌شده‌ی نوت‌بوک‌ها برداشته شده‌اند و نتیجه‌ی اجرای مجدد نیستند.

| مدل | تنظیمات | دقت آموزش | دقت آزمون |
|---|---|:---:|:---:|
| **Decision Tree** | `criterion='gini'`, `max_depth=5` | **83.56%** | **83.85%** |
| KNN | `n_neighbors=24` | 76.60% | 76.92% |

## 🚀 نصب و اجرا

Python را نصب کنید، سپس در پوشه‌ی پروژه وابستگی‌ها را نصب کنید:

```bash
python -m pip install -r requirements.txt
```

نوت‌بوک‌ها را با Jupyter باز کنید:

```bash
jupyter notebook
```

هنگام اجرای سلول‌های مربوط به بارگذاری داده، پنجره‌ی انتخاب فایل باز می‌شود؛ فایل `diabetes.csv` را انتخاب کنید.
